# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| MVP     | :white_check_mark: |

---

## Reporting a Vulnerability

We take the security of live streamers, their broadcast setups, and their communities seriously.

If you discover a security vulnerability, prompt injection exploit, or sensitive credential leak within ChatSignal:

1. **Do not create a public GitHub issue.**
2. Send an email to the repository owner or submit a private security advisory via GitHub Security Advisories.
3. Include:
   * A detailed description of the vulnerability.
   * Steps to reproduce the issue (proof-of-concept payload or script).
   * Potential impact on the streamer's machine or Twitch account.

---

## Response Timeline

* **Initial Acknowledgement**: Within 48 hours of report submission.
* **Triage & Assessment**: Within 5 business days.
* **Remediation & Patch**: Target release within 14 business days depending on severity.
